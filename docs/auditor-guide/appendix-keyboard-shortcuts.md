# Appendix: Keyboard Shortcuts

> Quick reference for keyboard shortcuts in the AuditForge web UI.

---

## Global

| Shortcut | Action |
|---|---|
| `?` | Open shortcut help overlay |
| `Ctrl+K` / `Cmd+K` | Open command palette |
| `Esc` | Close modal or panel |
| `Alt+E` | Focus engagement switcher |

---

## Working Paper Editor

| Shortcut | Action |
|---|---|
| `Ctrl+B` / `Cmd+B` | Bold |
| `Ctrl+I` / `Cmd+I` | Italic |
| `Ctrl+Z` / `Cmd+Z` | Undo |
| `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Redo |
| `Ctrl+S` / `Cmd+S` | Save (triggers manual sync checkpoint) |
| `Ctrl+Enter` | Finalize working paper |
| `Alt+L` | Open clause-link picker |
| `Alt+E` | Open evidence drawer |

---

## Interview Composer

| Shortcut | Action |
|---|---|
| `Space` | Accept highlighted question |
| `Delete` | Skip highlighted question |
| `Alt+Up` / `Alt+Down` | Reorder selected question |
| `Alt+A` | Accept all high-confidence attributions in current session |
| `Alt+R` | Open attribution review panel |

---

## Candidate Findings Panel

| Shortcut | Action |
|---|---|
| `P` | Promote selected candidate finding |
| `D` | Dismiss selected candidate finding |
| `E` | Edit selected candidate finding |
| `Tab` | Move to next candidate finding |
| `Shift+Tab` | Move to previous candidate finding |

---

## Evidence Panel

| Shortcut | Action |
|---|---|
| `U` | Open upload dialog |
| `C` | Confirm selected extracted claim |
| `R` | Reject selected extracted claim |
| `L` | Link selected evidence to current working paper |
