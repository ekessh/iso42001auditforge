# Support

For all questions, bug reports, security disclosures, licensing requests,
and feature requests, contact:

**Ekessh Thoralingam** — <ekesshtks@gmail.com>

This repository is private and maintained by a single owner. There is no
public issue tracker, no community pull-request acceptance, and no
external collaborator role.

## What to include in a support request

- Your name and organization
- Whether you are an existing licensee, a prospective licensee, or a
  security researcher
- A clear summary of the issue or request
- For bugs: reproduction steps, expected vs actual behavior, and (if
  applicable) the AuditForge version + deployment context
- For security findings: see [SECURITY.md](SECURITY.md) for the
  responsible-disclosure protocol

## Response targets

- Critical security: within 1 business day
- Licensing inquiries: within 3 business days
- All other requests: best effort

## Out of scope

- Public discussion forums (none are operated)
- Direct messages on social platforms
- Pull requests from non-licensed contributors (these will be closed)
